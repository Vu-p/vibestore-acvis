# Project Glossary

Shared vocabulary and terms used across `ts-node-app`.

| Term | Definition | Synonyms to avoid |
| :--- | :--- | :--- |
| **Task** | A discreet unit of work managed by TaskManager with unique UUID, title, completion status, and timestamp. | job, work item |
| **TaskManager** | In-memory service coordinating creation, retrieval, and status updates of tasks. | task service, worker |
| **ProjectInfo** | Metadata describing project name, version, runtime environment, and start timestamp. | app config, system status |
